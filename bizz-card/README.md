# BizzCard

Simple Flutter app that shows a static business card with your personal information.

## Features

- App bar titled `BizzCard` with blue accent color.
- Circular profile picture loaded from `assets/profile.png`.
- Full name, age, phone number, and email displayed in a centered card.

## Project Structure

- `lib/main.dart` – main Flutter entry point and UI.
- `assets/profile.png` – profile image asset.
- `pubspec.yaml` – Flutter configuration and asset declaration.

## Running the App

From the `bizz-card` folder:

```bash
flutter pub get
flutter run
```

Run on an Android device or emulator detected by `flutter devices`.
